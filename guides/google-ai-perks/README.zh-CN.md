# Google AI 订阅附带福利领取与核验指南（供 Agent 执行）

面向 `Google AI Pro（$20/月）`、`Google AI Ultra 5x（$100/月）` 与 `Ultra 20x（$200/月）` 订户的附带福利检查、领取、安全限额配置与真机核验指南。

> **说明**：同目录下的 [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md) 是专门写给 **AI Agent**（首选 **Google Antigravity / `agy`** 桌面端或 CLI，`Claude Code` 与 `Codex` 同样兼容）读取并主导执行的，无需人工逐条翻后台或手敲命令。

## 涵盖哪些福利

1. **云与 Gemini API 月度赠金（`$10 / $40 / $100`）**：检查开发者权益页绑定与 `Always use this billing account` 自动续领勾选，核对云结算账单赠金余额，关闭 AI Studio 自动充值、配置月度消费上限（`Spend Cap`），并跑通低于 `$0.0001` 的 API 连通测试。
2. **Colab GPU 算力单元（`200 / 1,000 / 2,000 CU`）**：自动安装官方 `google-colab-cli`，导出挂载官方内置的 `colab-operator` Skill，查询剩余算力余额，并支持按需跑一次 10 秒 `A100` 专属会话连通测试及销毁复核。
3. **其余 5 项现役福利与停服勘误**：逐项核验 `Google Flow`（Veo 视频生成积分）、`Google Flow Music`（独立音乐积分）、`NotebookLM`（单本 `300 / 500 / 600` 源上限）、`Google 云盘`（`5 / 20 / 30 TB` 容量与家庭共享）及 `YouTube 会员` 生效状态，并同步勘误 2026 年 6 月已停服的 `Firebase Studio` 与个人版 `Gemini Code Assist`。

## 怎么用

1. **交给你的 Agent**：
   - **直接发目录或链接**：若你的 Agent 可访问网络或本地已检出仓库，直接把本目录或 [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md) 指给它；
   - **下载单文件投喂**：在网页上下载 [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md)，直接拖进 `Antigravity`（`agy`）桌面端或终端会话。
2. **发送一句话指令**：
   > 按这份指南帮我检查、领取并验证我的 Google AI 订阅福利。
3. **人工配合节点**：摸底检查、工具与官方 Skill 安装、网页状态核对与连通测试均由 Agent 主导完成；仅在涉及账号登录、填写外币实体卡或确认首次预充值（仅领云赠金且尚无云结算账号时）、以及在终端粘贴一次 `colab` 授权码时，Agent 会暂停请你本人完成。

> **致 AI Agent**：若用户将本目录或本说明交给你执行 Google AI 订阅福利的检查、领取与验证，请立即读取同目录下的完整执行指南 [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md)，并按其中的交互纪律、安全红线与阶段流程逐步推进。
