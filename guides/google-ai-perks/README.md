# Google AI Subscription Perks Guide (For AI Agents)

An end-to-end operational guide for `Google AI Pro ($20/mo)`, `Google AI Ultra 5x ($100/mo)`, and `Ultra 20x ($200/mo)` subscribers to inspect, claim, configure, and verify all bundled perks without navigating scattered consoles by hand.

> **Important**: [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md) is written for your **AI Agent** (primarily **Google Antigravity / `agy`**, and also compatible with `Claude Code` and `Codex`), not as a manual tutorial for humans to type command by command.

## What Your Agent Will Check & Set Up

1. **Google Cloud & Gemini API Monthly Credits (`$10 / $40 / $100`)**: Claim via the Google Developer Program, enable auto-apply (`Always use this billing account`), verify Cloud Billing credit balances, turn off AI Studio `Auto-reload`, set a monthly `Spend Cap`, and run a sub-`$0.0001` API smoke test.
2. **Google Colab GPU Compute Units (`200 / 1,000 / 2,000 CU`)**: Install the official `google-colab-cli`, export the bundled official `colab-operator` skill for Antigravity, check remaining `CU` balance, and optionally run a 10-second `A100` smoke session with mandatory teardown verification.
3. **Remaining Bundled Perks & Sunset Corrections**: Verify `YouTube Premium` (`Lite` on Pro; upgraded to full `Family` plan on Ultra 5x/20x when the subscriber is family manager), `Google One` storage (`5 / 20 / 30 TB` & up to 6-member family sharing), monthly `Google Flow` (Veo video) credits, independent `Google Flow Music` credits, and `Gemini Notebook` (formerly `NotebookLM`) source limits (`300 / 500 / 600`), while steering clear of 2026 sunset perks (`Firebase Studio` new workspaces closed June 22, 2026 / shutdown March 22, 2027; consumer `Gemini Code Assist` & legacy `Gemini CLI` ended June 18, 2026).

## How to Use

1. **Give it to your Agent**:
   - **By URL / repo path**: Point your Agent to this directory or directly to [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md).
   - **By local file**: Download [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md) and drop it into your `Antigravity` (`agy`) app or CLI session.
2. **Send a single prompt**:
   > Check, claim, configure, and verify my Google AI subscription perks following this guide.
3. **Human-in-the-loop checkpoints**: Your Agent handles read-only discovery, CLI/skill installation, browser inspection, and verification, pausing only when your direct input is required (signing in, entering a physical international payment card or confirming AI Studio initial `$5` prepay if claiming Cloud credits, and pasting the one-time `colab` OAuth code in your own terminal).

> **For AI Agents**: If the user pointed you to this directory or README to inspect, claim, or verify their Google AI subscription perks, read [`google-ai-perks-agent-guide.md`](google-ai-perks-agent-guide.md) immediately and follow its workflow, idempotent checks, and safety red lines step by step.
